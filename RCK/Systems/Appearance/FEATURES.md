# RCK.Appearance features

RCK.Appearance lets campaign makers build appearance pools with compatibility trait names. Add one or more traits from a category to a custom character. NPCs roll from those pools when they spawn, and the same NPC keeps the same result on reload. `Dynamic_Player_Appearance` lets the player version of a custom character use the same pools.

Most traits add one or more choices to a visual roll. Special traits such as `_50`, `_75`, `Shirtless`, `Pantsless`, `Mask_Override`, and visibility traits change the final roll.

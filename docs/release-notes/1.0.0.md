The first public release of RCK (Rogue Content Kit), a custom-content mod for Streets of Rogue campaigns, packed with everything it needs in one zip. Campaigns and characters made for Custom Content Utilities (CCU) work unchanged.

**⬇ Download `RCK-Pack-1.0.0.zip` from Assets below.** You don't need the "Source code" files; they're for developers.

Русский и 简体中文: see below.

## What's in the zip

- **BepInEx 5.4.23.5**, the mod loader
- **RogueLibs 4.0.0-rc.3**, the modding library by Chasmical (Abbysssal), released by Dzhake, unmodified
- **RogueLibsPlus 1.0.0**, fixes and extra APIs on top of RogueLibs
- **RCK 1.0.0**: designer traits for NPCs, NPC goals, mutators, factions, investigate text, container items and more

## Install

1. Download `RCK-Pack-1.0.0.zip` below.
2. In Steam, right-click Streets of Rogue and choose **Manage > Browse local files**.
3. Extract everything in the zip into that folder, next to `StreetsOfRogue.exe`. Choose **Replace** if asked.
4. Start the game. The bottom left of the main menu shows RogueLibs (`RL v4.0.0-rc.3`), `RL+ v1.0.0` and `RCK v1.0.0`. A red line there means something needs fixing, and it says what to do.

- **Campaigns:** subscribe on the Steam Workshop, then start it from the main menu with **Custom Content > Load Campaign**.
- **Coming from CCU:** delete `BepInEx\plugins\CCU` first. The menu tells you if you forget.
- **Update:** extract the new zip over the old one.
- **Steam Deck and Linux:** run the Windows version of the game through Proton, with the launch option `WINEDLLOVERRIDES="winhttp=n,b" %command%`.

Designer mode, uninstalling and troubleshooting: see the [README](https://github.com/lachlanmcglennon/RogueContentKit#install-players).

## Known limits

- Windows, or Steam Deck and Linux through Proton. The native Linux and macOS versions of the game are not supported.
- In-game text from RCK is English only.
- Designer traits are hidden from the character creator until you turn on designer mode (a button at the top of the Traits list); the list changes the next time you open the character creator.
- RCK's player traits need no Chicken Nuggets: 14 of them (such as Trigger Happy and Ammo Stocker) can be offered when you level up, in ordinary runs too, even though the character creator hides 12 of them while designer mode is off; to keep them out of ordinary runs, turn them off in the Doctor's **Unlock Traits** menu at the Home Base (campaigns and the Daily Run ignore that switch).

## Bugs

Open an [issue](https://github.com/lachlanmcglennon/RogueContentKit/issues). Attach `BepInEx\LogOutput.log` from the game folder, name the campaign, and say what you did and what happened.
